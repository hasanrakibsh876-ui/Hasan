4. Cipher descriptions

Vigenère: A classical cipher that shifts letters according to a repeating keyword.

AES-256-GCM: A modern symmetric authenticated-encryption algorithm using a 256-bit key. It checks message integrity as well as encrypting the data.

Caesar Cipher: A substitution cipher that shifts each letter by a fixed number of positions in the alphabet.
